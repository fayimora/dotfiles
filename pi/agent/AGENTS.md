# Development Guidelines

- Detect and follow the existing project's architecture, conventions, and tooling.
- Test meaningful behavior changes where practical.
- Update documentation when changing public APIs or configuration.

## Writing rules

For simple answers, confirmations, and status updates, use plain,
direct language without loading a skill.

Before writing substantial prose, documentation, or longer explanations,
read ~/.agents/skills/unslop/SKILL.md and apply its rules. Don't reread
it while its instructions are still in context.
